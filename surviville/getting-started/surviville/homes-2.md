# Build Limits



### Redstone & Utility Block Limits

To maintain server performance, VilleMC enforces placement limits on certain blocks per claim. Once a limit is reached, you won't be able to place any more of that block until some are removed.

#### Limits

| Block         | Limit |
| ------------- | ----- |
| Hopper        | 64    |
| Chest         | 64    |
| Composter     | 64    |
| Dropper       | 64    |
| Dispenser     | 64    |
| Piston        | 32    |
| Sticky Piston | 32    |
| Observer      | 32    |
| Trapped Chest | 32    |
| Furnace       | 16    |
| Blast Furnace | 16    |
| Smoker        | 16    |
| Brewing Stand | 8     |
| Jukebox       | 8     |
| Beacon        | 4     |
| Pot           | 50    |



***

### Tips and Good to Know

⭐ Large automatic farms should be designed with these caps in mind to avoid interruptions\
⭐ If you need more storage, consider using **Barrels** - they are not limited.\
⭐ These limits apply **per claim**, not per player.<br>
